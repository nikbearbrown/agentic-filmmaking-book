# Skills for Filmmakers: the catalog

This catalog is research for the two courses. The skills made from it are in the *Agentic Filmmaking* skill repo, [/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking](/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking). The third-party copies below stay here, not in that repo, so no agent installs them by accident.

## Executive summary

- **What this is:** agent skills that do a real filmmaking job, gathered on 2026-11-17 for two courses, *AI Filmmaking* (for trained filmmakers like Galen) and *Agentic Filmmaking* (for a general audience), and grouped by production stage. Nothing here was run or tested.
- **Counts:**
  - **120 skills do filmmaking work:** 107 third-party and 13 of Bear's own. Of the third-party ones, 102 are copied here. The other 5 are listed with GitHub links only, because their licenses do not allow copying: GPL-3.0 (1), CC-BY-NC-ND (1) and Mirage's proprietary terms (3).
  - **33 n8n agents** are listed too.
  - **60 more of Bear's skills** make explainer, lecture and channel videos rather than films from a screenplay. They have their own section near the end.
  - **48 borderline items** are listed but not copied.
- **Strongest by stage:**
  - **Screenplay:** thin. There is the Adam Curtis narration chain and zenstory's video-script, both for narration rather than drama.
  - **Look:** HyperFrames creative (sets the style before any animation).
  - **World:** Kolbo Visual DNA, Higgsfield Soul ID, and character-prompt-builder (listed only: GPL-3.0).
  - **Storyboards:** FinShinjuku's storyboard cut table, the video-shotcraft shot cards, and Bear's greybox previz.
  - **Budget:** only Runway's credit check.
  - **Generation:** Replicate's prompt-videos, kling-ai, shortfilm-prompt, and Runway's generate scripts.
  - **Performance:** HeyGen's avatar, video and translate skills.
  - **Sound:** Runway audio, CellCog audio and music, and doseedo-film.
  - **Editing:** kajisho5's ffmpeg-skill, Remotion's own skills, and the HyperFrames set.
  - **VFX:** Pika's vfx and fix-my-look.
  - **Distribution:** the LattifAI caption tools, yt-trailer, and Bear's post and godot-trailer.
  - **Whole film:** Bear's unreal-reels, and kolbo-filmmaking.
- **Gaps:** nothing turned up for Fountain or screenplay formatting, script breakdown, budgeting, upscaling or color grading. The first three are the core of Ch 1 (screenplay to shot table) and Ch 7 (budget) in *AI Filmmaking*.
- **Four skills made from these (2026-11-17):** cinematic-shots, film-sound, film-edit and motion-graphics, rewritten in the style of Bear's skills library from the 93 permissively licensed third-party skills here. They are in the *Agentic Filmmaking* skill repo, [/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking](/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking), with a guide skill that walks through the whole process. Each SOURCES.md says which skills were used and which were read and left out. Each one has a SOURCES.md that cites every repository it drew on. They are not yet tested on a real shot. See "The four film skills" below.
- **Cautions:** most generation skills need a paid account and an API key. Some install tools with `curl | sh`. See "Cautions" below.

- **Tested:** the ffmpeg commands only. film-edit's 35 recipe blocks were run verbatim on synthetic clips under zsh and bash; film-sound's mix recipes were run on synthetic audio (the mix landed at -16.1 LUFS). The burn-in and drawtext recipes need an ffmpeg built with libass and freetype; Homebrew's ffmpeg 8.1.2 lacks them, so they were tested with ffmpeg@6.
- **Not tested:** the generation, voice and music steps. Nothing was generated and nothing was spent.
- **Bear's own rules** (ai-filmmaking/RULES.md), the course plan and filmkit.py are the core of the timing, mix, cost and still-checking steps. The skills cite them as "one film" or "the author's films", never by name.
- **Still not covered:** screenplay file formats (Fountain), production scheduling, color grading, on-set sound recording, platform loudness targets, and match-moving.
- **What the sources got wrong**, as recorded in each SOURCES.md:
  - vendor skills that spend money without asking;
  - HyperFrames skills that update themselves silently and send feedback reports by default;
  - voice-cloning skills with no consent step;
  - sources that rewrite the user's script or make the agent the creative lead;
  - one ffmpeg recipe that fails as printed.

The 13 repositories fetched on 2026-11-17 also carry their LICENSE file from that commit. Each repository folder also holds that repository's LICENSE file. The Remotion and Higgsfield copies, which Bear had installed locally, have no recorded license, so they are kept out of the public repository.
- [catalog.json](/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking-book/skills-catalog/catalog.json) has one record per kept item, n8n workflows included.

## Cautions

- Nothing in this folder was run or tested. Third-party files are copied text: 74 from the auditor's quarantine and 28 fetched from GitHub at the pinned commit on 2026-11-17.
- doseedo-audio and doseedo-film install a command-line tool globally with `npm install -g @doseedo/cli@latest` (unpinned). hyperframes-registry runs `npx hyperframes` for every lookup, which fetches the latest package each time. The Kolbo skills need a Kolbo account and its MCP server.
- Five skills are listed only, because their licenses do not allow copying: character-prompt-builder (GPL-3.0), vse-python (CC-BY-NC-ND-4.0), and tesseract-3d, tesseract-motion and tesseract-video (Mirage's Terms of Service, which forbid copying or distributing any part of the plugin).
- Most generation, voice and dubbing skills need a paid account and an API key: Runway, Kling, HeyGen, Higgsfield, CellCog, Kolbo, Pika, StarReel (prepaid), fal.ai, MiniMax, ListenHub, LattifAI, Gemini.
- Several skills install a command-line tool with `curl ... | sh` (Runway's uv step, the Higgsfield CLI, the HeyGen CLI). Read the install line before letting an agent run it.
- The HeyGen HyperFrames skills (music-to-video, embedded-captions, motion-graphics and others) tell the agent to run `npx hyperframes skills update` silently at the start, which fetches and overwrites skill files.
- yt-trailer and similar tools download other people's videos. They are only safe for footage you own or have rights to.
- Pika's viral-fake templates (kiss-cam, stagefight, baseball broadcast) and ad templates were left out on purpose.
