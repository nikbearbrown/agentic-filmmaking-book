# Agentic Filmmaking: the book

Folder: /Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking-book

## Executive summary

- **What this is:** the book repo for *Agentic Filmmaking*, a self-paced online course for a general audience without a film background. These are people who probably know ChatGPT, and maybe a little Midjourney or Higgsfield. Compared with the filmmakers' course, it spends much more time on story and filmmaking, and on why they are critical. [Bear, 2026-11-17]
- **Status:** planning only. The plan is the 2026-11-16 Blueprint (an introduction, 15 chapters and a capstone, with craft taught as vocabulary), and it is not yet revised for this audience. GATE 0 is unsigned.
- **Sister course:** *AI Filmmaking*, for trained filmmakers who already have a script and a vision, like Galen. It is in [/Users/bear/Documents/CoWork/bear-textbooks/books/ai-filmmaking](/Users/bear/Documents/CoWork/bear-textbooks/books/ai-filmmaking).
- **The skills:** the *Agentic Filmmaking* skill repo is separate: [/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking](/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking). It holds a guide skill and four stage skills (cinematic-shots, film-sound, film-edit, motion-graphics). The research behind them is the catalog in this repo, [/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking-book/skills-catalog/README.md](/Users/bear/Documents/CoWork/bear-textbooks/books/agentic-filmmaking-book/skills-catalog/README.md), which lists 120 third-party and Bear skills that do filmmaking work, plus 33 n8n agents. The four skills' ffmpeg commands were tested on synthetic media; the generation steps have not been tested.
- **Renamed 2026-11-17:** this folder was books/agentic-filmmaking until Bear made that name the skill repo.
- **Open:** the pantry folder (the film books this plan was built from) was missing on 2026-11-17. The plan still cites it.
